# Админка: VIP по ID и белые SVG

В карточке каждого пользователя есть кнопка `VIP`. Фиолетовая кнопка
назначает административный грант, золотая снимает только этот грант.
Эффективный VIP от покупки, прежнего неизвестного источника или другого
права остаётся активным. При таком праве карточка показывает пояснение.

Кнопка меняет цвет после подтверждения сервера, на месте того же DOM-узла:
фон, граница и мягкая тень переходят за 300 мс. При reduced motion переход
и вращение индикатора отключены. В работе кнопка disabled/aria-busy;
повторные запросы из одного интерфейса блокируются. При ошибке прежний
серверный цвет сохраняется и показывается уведомление с белой SVG-иконкой.

Контракт:

```text
POST /api/admin/vip
X-Telegram-Init-Data: ...
{"user_id": 123456, "enabled": true}
```

Ответ содержит `target_user` с `isVip`, `hasSub`, `vip_admin_granted`,
`vip_protected` и `admin.approved_users` — список активных административных
грантов. Состояние после перезагрузки берётся из `users[]` backend.
Цвет определяется `vip_admin_granted`, эффективный статус — `isVip`.
На старом backend без двух булевых полей VIP-кнопка отключена: нельзя
посылать `enabled:false` серверу, который может принять его за назначение.
Удаление из прежнего VIP-списка также отключено без подтверждённого источника:
старый DELETE не должен случайно отменить защищённый доступ.
Сначала требуется совместимый серверный PR.

Карточка обновляется без замены DOM, сброса поиска, pagination или позиции
внутреннего списка. Отдельно синхронизируется список назначенных VIP.
Устаревшие ответы загрузки не затирают подтверждённую VIP-операцию.
Старые добавление по username и удаление из списка поддержаны для совместимости;
основной новый путь работает с numeric Telegram ID и не требует username.

Декоративные эмодзи заголовков, кнопок, поиска, административной навигации,
подарков и административных уведомлений заменены inline SVG 24×24 со
stroke-width 1.7 и белым мягким свечением. Золотое оформление используется
только для активной VIP-кнопки. Пользовательские имена/тексты с эмодзи
не переписываются, функциональные цвета ошибок/подписок/предупреждений сохранены.
Новые библиотеки или внешние наборы иконок не подключаются.

Проверки:

```sh
node --check app.js
node tests/admin-users.cjs
```

Тест использует временный HTTP mock, искусственных пользователей и Chrome/
Playwright. Проверяются grant/revoke по ID без username, защищённый VIP,
повторное нажатие, отказ сервера, reload, точная синхронизация списка,
сохранение loaded pages/scroll/search, старый API, обычный пользователь,
белые иконки и золотой переход 300 мс, reduced motion, размеры 280–640 px.
Бот, production backend, VPN, реальные пользователи не вызываются.
