# FAQ — один Helper Stars

Третий вопрос: «Где купить Telegram Stars?». Белое SVG-рукопожатие сохранено.

Точный ответ:
«Мы подобрали сервис для покупки Telegram Stars. Перед покупкой сравните условия.»

Одна кнопка «Перейти»:
`https://t.me/HelperStars_Robot?start=8544752152`.
Второй сервис и его управляющий флаг исключены из UI. Старая настройка в
рабочем config.js игнорируется, не возвращает второй вариант и не требует
замены действующего файла с API URL.

Существующая волна текста не меняет восемь прежних ответов. Кнопка — отдельный
DOM-элемент: Y18 px, blur2, подъём400 ms. Пауза300 ms позволяет росту высоты420 ms
создать место для одной строки; промежуточные кадры проверены на обрезание.
При уходе/повторном входе сбрасываются ответ, выделение, кнопки и анимации.
Reduced motion и отключённые анимации применяют состояние непосредственно.

Для применимых коммерческих раскрытий сохранён SOL_FAQ_STARS_AD_INFO с
настоящими advertiser/erid/detailsUrl. Пустая конфигурация не показывает
дополнительных текстов. Значения вставляются как текст, ссылка сведений —
проверенный HTTPS. Условия публикации/маркировки должен проверить оператор;
вымышленные реквизиты или ценовые гарантии не добавлены.

`node tests/info-faq.cjs`: 20 browser checks — тексты, точный единственный URL,
порядок, волна, Liquid Rise, reset, размеры, resize, reduced motion, disclosure,
старые WebView API, клавиатура/touch/Unicode. Внешние сервисы не вызываются.
