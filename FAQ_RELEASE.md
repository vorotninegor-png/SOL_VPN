# FAQ: Stars, Liquid Rise и сброс ответа

В списке девять вопросов. «Где купить Telegram Stars?» расположен третьим;
после подключения/ключа идут покупка Stars, ПК, скорость, устройства,
доступ к играм, ловля комет и реферальный процент. У прежних восьми ответов
сохранены текст и стабильные ID, новый ответ имеет ID 9.

Новый ответ и названия двух вариантов взяты дословно из ТЗ. Ссылки:

- Вариант №1: `https://t.me/HelperStars_Robot?start=8544752152`;
- Вариант №2: `https://t.me/x10starsbot?start=8fee8aacda15d7c3`.

Они реализованы отдельными DOM-контролами, без разбиения на анимированные
буквы. По нажатию используется Telegram `openTelegramLink`, а в обычном
браузере — HTTPS-ссылка с `noopener noreferrer`. Настоящие боты при разработке
не открываются. Названия ботов не показываются в строках вариантов.

`window.SOL_FAQ_STARS_SECOND_ENABLED` по умолчанию отсутствует/false:
вторая строка видна с недоступной кнопкой, переход не выполняется. Включать
её только после отдельного подтверждения условий сервиса. Настройка приведена
в `config.example.js`; рабочий пользовательский `config.js` не изменён.

Для применимых рекламных раскрытий предусмотрена публичная конфигурация
`window.SOL_FAQ_STARS_AD_INFO = { advertiser, erid, detailsUrl }`. В примере
поля пустые. При заполнении проверенными данными появляется компактное
«Реклама · сведения» с раскрытием; текст вставляется через `textContent`,
дополнительная ссылка допускается только HTTPS без userinfo. Идентификаторы
рекламы и рекламодатель не выдумываются. До публикации оператор должен
проверить квалификацию материала, условия реферальных сервисов, применимые
правила маркировки/учёта рекламы и заполнить требуемые реальные сведения.
Наличие этой настройки не означает выполненную юридическую проверку.

Волна букв сохранена: 280 мс локальная смена, шаг 12 мс с ограничением общей
волны, перекрытие 40 мс и высота 420 мс. После завершения текста отдельные
строки поднимаются с Y=18 px, blur=2 px, opacity 0→1 за 400 мс с easing
`cubic-bezier(0.22, 1, 0.36, 1)`, интервал между ними 120 мс. Небольшой
запуск высоты перед строками не позволяет обрезать уже читаемые кнопки.

При смене вопроса живые ссылки сразу отключаются, прежние строки исчезают
вместе с ответом. Повторный вход в «Инфо» сбрасывает выбор/подсветку и
показывает исходную подсказку той же волной. Уход со вкладки приостанавливает
WAAPI, новый revision не позволяет старым promise восстановить прежний ответ.
ResizeObserver учитывает текст, строки и раскрытие сведений. При reduced
motion и в старом WebView без WAAPI состояние устанавливается сразу.

`tests/info-faq.cjs` проверяет тексты/порядок/SVG, точные ссылки и выключенный
вариант №2, параметры и промежуточные кадры Liquid Rise, высоту, отмену,
сброс при возвращении, reduced motion, старые API, клавиатуру, touch,
экраны от 280 px и безопасное раскрытие сведений. Тесты полностью локальны.
`SOL_FAQ_SCREENSHOT_DIR` сохраняет также снимки нового ответа с вариантами.
