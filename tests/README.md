# Проверка раздела «Инфо»

Нужны Node.js и Playwright с Chromium, доступный через `require('playwright')`.
Запуск из корня репозитория:

```sh
node --check app.js
node tests/info-faq.cjs
node tests/admin-users.cjs
node tests/stars-checkout.cjs
```

Для установленного Chrome задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` — полный
путь к исполняемому файлу. Необязательная переменная `SOL_FAQ_SCREENSHOT_DIR`
включает сохранение снимков экранов шириной 320 и 390 px.

Тест поднимает временный локальный HTTP-сервер, подменяет Telegram и bootstrap API,
блокирует внешние запросы. Проверяет восемь ответов, символы и пробелы,
подсветку, промежуточные кадры изменения высоты, быстрые переключения,
возврат во вкладку, размеры от 280 px до планшета и альбомную ориентацию,
клавиатуру, reduced motion и отсутствие некоторых API старых WebView.
Ни бот, ни Xray, ни настоящий backend не запускаются.

`stars-checkout.cjs` проверяет каталог XTR, disabled-состояние, точную цену
до открытия счёта, заголовок идемпотентности, отмену/ошибку, повторы после
перезагрузки, сохранение выставленной цены после изменения коэффициента,
ожидание серверного подтверждения и отсутствие выдачи подписки по клиентскому
`paid`. Все ответы и Telegram API подменены. Настоящие Stars не расходуются.
Изменён только второй фрагмент ответа «Как ловить кометы?»; ожидаемый полный
ответ закреплён в `info-faq.cjs`, остальные семь ответов и волна сохранены.

В проекте нет отдельной сборки и существующего тестового раннера.
Админские проверки используют 125 искусственных пользователей: все страницы,
поиск за пределами первой страницы, отмена устаревших ответов, профиль с username
и без него, приватность, сообщения, сохранение черновиков, подарки/VIP,
ошибки API, fallback старого сервера и отсутствие админского входа у обычного пользователя.
Перед выпуском дополнительно проверьте Mini App на физических Android/iOS:
все вопросы, изменение ориентации и системную настройку уменьшения движения.

## Непрерывная волна FAQ

`info-faq.cjs` проверяет одновременную видимость старого хвоста и нового начала,
отсутствие пустого кадра, уменьшение/размытие символов, переходы короткий/длинный,
сохранение текущего кадра при прерывании, ограничение в два визуальных слоя,
повторные нажатия, тач-ввод на мобильном размере и Unicode/пробелы/новые строки.
Тач-проверка в Chromium не заменяет проверку настоящего Telegram Android.

Параметры в `app.js`, объект `FAQ_ANIMATION`: `swapDurationMs=280`,
`staggerMs=12`, `maxWaveMs=1200`, `overlapMs=40`, `heightDurationMs=420`,
`blurPx=1.4`. Локальная смена занимает 280 мс, вход следующего символа начинается
до окончания выхода предыдущего слоя. Высота короткого ответа уменьшается после
затухания последней строки старого, чтобы её не обрезать.

Тексты вопросов/ответов дословно восстановлены из первого пользовательского ТЗ
«Обновление раздела Инфо SOL VPN», предоставленного до PR №3. В нём используется
«Туннель», а во втором ответе — «Скопировать»; эти формулировки сохранены без правки.

Необязательный `SOL_FAQ_PREVIEW_DIR` сохраняет шестисекундную последовательность
кадров и `frames.json` для визуальной оценки скорости без установки приложения.
